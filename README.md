# mock-ds

DevStyler magazine UI built with React + Vite.

Live site: https://mchernev.github.io/mock-ds/

## Development

```bash
npm install
npm run dev
```

## Deploying changes

After editing, commit and push the source, then redeploy to GitHub Pages:

```bash
git add src/App.jsx && git commit -m "your message"
git push && npm run deploy
```

`git push` updates the source on `master`. `npm run deploy` rebuilds the app and publishes the new build to the `gh-pages` branch that GitHub Pages serves.
